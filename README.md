
# TrendPulse

TrendPulse is a Python data pipeline project that collects trending data from the Hacker News API, processes the data, performs analysis, and creates visualizations.

## Project Files

- `task1_fetch_data.py` - Fetches data from the Hacker News API
- `task2_data_processing.py` - Cleans and processes the collected data
- `task3_analysis.py` - Performs analysis on the processed data
- `task4_visualization.py` - Creates visualizations from the analysis results

## Technologies Used

- Python
- Requests
- Pandas
- Matplotlib
- Hacker News API

## How to Run

```bash
python task1_fetch_data.py
python task2_data_processing.py
python task3_analysis.py
python task4_visualization.py
